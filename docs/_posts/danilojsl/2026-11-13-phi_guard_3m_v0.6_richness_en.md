## Description

PHI Guard 3m v0.6 estimates an ordinal PHI exposure level on de-identified clinical text. It returns one document-level category per input document, not entity spans. A level is not a privacy certificate. Rounded size: about 3 million parameters.

## Predicted Entities

`NONE`, `TRACE`, `LOW`, `MODERATE`, `HIGH`, `VERY_HIGH`, `SATURATED`, `UNKNOWN`, `REVIEW_REQUIRED`

## How to use

Load DecisionModel.pretrained("phi_guard_3m_v0.6_richness", "en", "clinical/models"). Pass this name explicitly. Do not call setMode. Score the final de-identified note. Inspect metadata.level. The sample contrasts a masked note with Pt Maria Delgado, DOB 03/14/1956. Inspect result and metadata.status. A negative label is not a privacy certificate. The lookup name is lowercase.

```python
from pyspark.ml import Pipeline
from sparknlp.base import DocumentAssembler
import sparknlp_jsl
from sparknlp_jsl.annotator.classification import DecisionModel
spark = sparknlp_jsl.start()
notes = spark.createDataFrame([
 ("masked", "[NAME] visited [HOSPITAL] on [DATE]."), ("leaked", "Pt Maria Delgado, DOB 03/14/1956.")], ["case_id", "text"])
doc = DocumentAssembler().setInputCol("text").setOutputCol("document")
guard = DecisionModel.pretrained("phi_guard_3m_v0.6_richness", "en", "clinical/models")\
 .setInputCols("document").setOutputCol("phi_richness")
Pipeline(stages=[doc, guard]).fit(notes).transform(notes).selectExpr(
 "case_id", "phi_richness[0].result AS label", "phi_richness[0].metadata.status AS status"
).show(truncate=False)

```
```scala
import com.johnsnowlabs.nlp.DocumentAssembler
import com.johnsnowlabs.nlp.annotators.classification.DecisionModel
import org.apache.spark.ml.Pipeline
import org.apache.spark.sql.SparkSession
val spark = SparkSession.builder().getOrCreate()
import spark.implicits._
val notes = Seq(("masked", "[NAME] visited [HOSPITAL] on [DATE]."), ("leaked", "Pt Maria Delgado, DOB 03/14/1956.")).toDF("case_id", "text")
val doc = new DocumentAssembler().setInputCol("text").setOutputCol("document")
val guard = DecisionModel.pretrained("phi_guard_3m_v0.6_richness", "en", "clinical/models")
 .setInputCols("document").setOutputCol("phi_richness")
new Pipeline().setStages(Array(doc, guard)).fit(notes).transform(notes).selectExpr(
 "case_id", "phi_richness[0].result AS label", "phi_richness[0].metadata.status AS status").show(false)

```
