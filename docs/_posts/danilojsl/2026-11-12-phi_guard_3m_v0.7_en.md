## Description

PHI Guard 3m v0.7 classifies clinical text for PHI presence in original notes, or residual PHI, harmful PHI, and exposure level after de-identification. Select one task per stage. It does not locate or remove PHI, and a negative result does not certify privacy safety. Rounded size: about 3 million parameters. This is the no-argument DecisionModel.pretrained() name.

## Predicted Entities

`PHI_PRESENT`, `NO_PHI_PRESENT`, `PHI_LEAK`, `NO_PHI_LEAK`, `HARMFUL_PHI_LEAK`, `NO_HARMFUL_PHI_LEAK`, `NONE`, `TRACE`, `LOW`, `MODERATE`, `HIGH`, `VERY_HIGH`, `SATURATED`, `UNKNOWN`, `REVIEW_REQUIRED`

## How to use

Load DecisionModel.pretrained("phi_guard_3m_v0.7", "en", "clinical/models"). DecisionModel.pretrained() with no name downloads phi_guard_3m_v0.7. This version 0.7 artifact requires setMode before transform: raw, leak, harmful, or richness. One stage selects one task; all is not supported. Use copy() and a separate output column per task. raw scores the original document. leak, harmful, and richness score the final de-identified DOCUMENT. The example shows all four modes, including a fully masked note and a leaked note (Pt Maria Delgado, DOB 03/14/1956, MRN 004821), then wires DeIdentificationModel output column deidentified_document into leak mode. Inspect phi_present_prob, phi_leak_prob, harmful_leak_prob, or richness level and score_1 through score_6 for the selected task. The saved stage default columns are document -> phi_guard. The examples override them with stable task columns so a lookup rename does not change the pipeline. Do not use the model name as an output column. A scored result is one CATEGORY annotation: result is the label; metadata.status is scored; metadata.n_windows is the window count. Empty input returns UNKNOWN with status=empty. Over-length input returns REVIEW_REQUIRED with status=overlength. Those two are unscored statuses, not getClasses() labels. A negative label does not certify privacy safety, and the stage does not locate or remove PHI. The lookup name is lowercase and must match the code exactly.

from pyspark.ml import Pipeline
from sparknlp.base import DocumentAssembler
import sparknlp_jsl
from sparknlp_jsl.annotator.classification import DecisionModel

spark = sparknlp_jsl.start()  # Licensed runtime that contains DecisionModel.
# One stage has one mode. copy() keeps the loaded model and selects another task.
# raw reads the original document. leak, harmful, and richness read the final
# de-identified DOCUMENT. The synthetic masked_text column stands in for
# DeIdentificationModel.setOutputCol("deidentified_document").
notes = spark.createDataFrame([
    ("masked", "Example fictional de-identified note: [NAME] visited [HOSPITAL] on [DATE].", "Example fictional de-identified note: [NAME] visited [HOSPITAL] on [DATE]."),
    ("leaked", "Example fictional note: Pt Maria Delgado, DOB 03/14/1956, MRN 004821, phone 555-014-2291.", "Example fictional note: Pt Maria Delgado, DOB 03/14/1956, MRN 004821, phone 555-014-2291."),
], ["case_id", "text", "masked_text"])
original_doc = DocumentAssembler().setInputCol("text").setOutputCol("document")
masked = DocumentAssembler().setInputCol("masked_text").setOutputCol("deidentified_document")
base = DecisionModel.pretrained("phi_guard_3m_v0.7", "en", "clinical/models")
raw = base.copy().setMode("raw").setInputCols("document").setOutputCol("phi_raw")
leak = (base.copy().setMode("leak")
        .setInputCols("deidentified_document").setOutputCol("phi_leak"))
harmful = (base.copy().setMode("harmful")
           .setInputCols("deidentified_document").setOutputCol("phi_harmful"))
richness = (base.copy().setMode("richness")
            .setInputCols("deidentified_document").setOutputCol("phi_richness"))
result = Pipeline(stages=[original_doc, masked, raw, leak, harmful, richness]).fit(notes).transform(notes)
result.selectExpr(
    "case_id",
    "phi_raw[0].result AS raw_label",
    "phi_raw[0].metadata.phi_present_prob AS phi_present_prob",
    "phi_leak[0].result AS leak_label",
    "phi_leak[0].metadata.phi_leak_prob AS phi_leak_prob",
    "phi_harmful[0].result AS harmful_label",
    "phi_harmful[0].metadata.harmful_leak_prob AS harmful_leak_prob",
    "phi_richness[0].result AS richness_label",
    "phi_richness[0].metadata.level AS level",
    "phi_richness[0].metadata.status AS richness_status").show(truncate=False)

from sparknlp.annotator import SentenceDetector, Tokenizer, WordEmbeddingsModel
from sparknlp_jsl.annotator import (
    DeIdentificationModel, MedicalNerModel, NerConverterInternal)

# Wiring only: this replaces the synthetic deidentified_document column.
# NER may mask the identifiers, so this row is not a guaranteed leak label.
original = spark.createDataFrame([("Example fictional note: Pt Maria Delgado, DOB 03/14/1956, MRN 004821, phone 555-014-2291.",)], ["text"])
document = DocumentAssembler().setInputCol("text").setOutputCol("document")
sentence = SentenceDetector().setInputCols(["document"]).setOutputCol("sentence")
token = Tokenizer().setInputCols(["sentence"]).setOutputCol("token")
embeddings = (WordEmbeddingsModel.pretrained(
    "embeddings_clinical", "en", "clinical/models")
    .setInputCols(["sentence", "token"]).setOutputCol("embeddings"))
ner = (MedicalNerModel.pretrained("ner_deid_large", "en", "clinical/models")
       .setInputCols(["sentence", "token", "embeddings"]).setOutputCol("ner"))
chunks = (NerConverterInternal()
          .setInputCols(["sentence", "token", "ner"]).setOutputCol("ner_chunk"))
deid = (DeIdentificationModel.pretrained("deidentify_large", "en", "clinical/models")
        .setInputCols(["sentence", "token", "ner_chunk"])
        .setOutputCol("deidentified_document"))
wired = (DecisionModel.pretrained(
    "phi_guard_3m_v0.7", "en", "clinical/models")
    .setMode("leak")
    .setInputCols("deidentified_document")
    .setOutputCol("phi_leak"))
piped = Pipeline(stages=[document, sentence, token, embeddings, ner, chunks, deid, wired])
piped.fit(original).transform(original).selectExpr(
    "deidentified_document.result AS assessed_text",
    "phi_leak[0].result AS label",
    "phi_leak[0].metadata AS metadata").show(truncate=False)
