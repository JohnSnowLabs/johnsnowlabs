## Description

PHI Guard v7 (final) classifies clinical text for PHI presence in original notes or residual/harmful PHI and exposure level after de-identification. It emits one selected document-level category per input document; it does not locate or remove PHI, and a negative result does not certify privacy safety.

## Predicted Entities

`PHI_PRESENT`, `NO_PHI_PRESENT`, `PHI_LEAK`, `NO_PHI_LEAK`, `HARMFUL_PHI_LEAK`, `NO_HARMFUL_PHI_LEAK`, `NONE`, `TRACE`, `LOW`, `MODERATE`, `HIGH`, `VERY_HIGH`, `SATURATED`, `UNKNOWN`, `REVIEW_REQUIRED`

## How to use

Convert text to a DOCUMENT annotation with DocumentAssembler. For raw, score the **original** document before masking; for leak, harmful, or richness, feed the **final de-identified DOCUMENT** from your separate masking pipeline. Retrieve the assumed published entry with PhiGuardModel.pretrained("Medical_DM_3.5m_v0.7", "en", "clinical/models"), select one task with setMode("leak") (or raw, harmful, richness), then set its input/output columns before transforming. Use a separate stage instance and output column for each task; mode is a saved model parameter and all is not supported. Inspect CATEGORY.result **and** metadata.status: empty/overlength inputs are not scored privacy assessments. The example below uses fictional already-masked text, not an actual de-identification pipeline.

```python
from pyspark.ml import Pipeline
from sparknlp.base import DocumentAssembler
import sparknlp_jsl
from sparknlp_jsl.annotator.classification import PhiGuardModel

spark = sparknlp_jsl.start()  # Requires your licensed, matching Healthcare NLP runtime.
assembler = DocumentAssembler().setInputCol("text").setOutputCol("document")
guard = (PhiGuardModel.pretrained("Medical_DM_3.5m_v0.7", "en", "clinical/models")
         .setMode("leak")
         .setInputCols("document")
         .setOutputCol("phi_guard"))
notes = spark.createDataFrame(
    [("Example fictional note: [NAME] visited [HOSPITAL] on [DATE].",)],
    ["text"])
result = Pipeline(stages=[assembler, guard]).fit(notes).transform(notes)
result.selectExpr("phi_guard[0].result AS label",
                  "phi_guard[0].metadata AS metadata").show(truncate=False)
```
```scala
import com.johnsnowlabs.nlp.DocumentAssembler
import com.johnsnowlabs.nlp.annotators.classification.PhiGuardModel
import org.apache.spark.ml.Pipeline
import org.apache.spark.sql.SparkSession

// Run with a valid Healthcare NLP license and matching licensed/public JARs.
val spark = SparkSession.builder().master("local[2]").appName("PHI Guard v7").getOrCreate()
import spark.implicits._
val notes = Seq("Example fictional note: [NAME] visited [HOSPITAL] on [DATE].").toDF("text")
val assembler = new DocumentAssembler().setInputCol("text").setOutputCol("document")
val guard = PhiGuardModel.pretrained("Medical_DM_3.5m_v0.7", "en", "clinical/models")
  .setMode("leak")
  .setInputCols("document")
  .setOutputCol("phi_guard")
val result = new Pipeline().setStages(Array(assembler, guard)).fit(notes).transform(notes)
result.selectExpr("phi_guard[0].result AS label", "phi_guard[0].metadata AS metadata")
  .show(false)
```
