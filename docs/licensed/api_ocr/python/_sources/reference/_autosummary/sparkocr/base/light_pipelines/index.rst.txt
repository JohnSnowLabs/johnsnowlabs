.. py:class:: LightPipeline(pipelineModel: pyspark.ml.pipeline.PipelineModel)

   Creates a LightPipeline from a Spark OCR PipelineModel.

   LightPipeline is a Spark OCR specific Pipeline class equivalent to Spark
   ML Pipeline. The difference is that it’s execution does not hold to
   Spark principles, instead it computes everything locally (but in
   parallel) in order to achieve fast results when dealing with small
   amounts of data. This means, we do not input a Spark Dataframe, but a
   string or an Array of strings instead, to be annotated. To create Light
   Pipelines, you need to pass an already trained (fit) Spark ML Pipeline.


   :param pipelineModel: The PipelineModel containing Spark OCR Annotators
   :type pipelineModel: :class:`pyspark.ml.PipelineModel`

   .. rubric:: Notes

   Use :meth:`.fullAnnotate` to also output the result as
   :class:`.Annotation`, with metadata.

   .. rubric:: Examples

   >>> from sparkocr.base import LightPipeline
   >>> light = LightPipeline(pipeline.fit(data))
   >>> light.fromLocalPath("./documents/pdfs")
