   .. py:method:: readDataset(spark, jsonPath, imagesFolder, partitions=8, storage_level=pyspark.StorageLevel.DISK_ONLY)

      Reads the dataset from an external resource.

      :param spark: Initiated Spark Session with Spark NLP
      :type spark: :class:`pyspark.sql.SparkSession`
      :param jsonPath: the path where you unzip the files for DocVQA
      :type jsonPath: str
      :param imagesFolder: the folder containing all the images
      :type imagesFolder: str
      :param partitions:
      :type partitions: sets the minimum number of partitions for the case of lifting multiple files in parallel into a single dataframe. Defaults to 8.
      :param storage_level:
      :type storage_level: sets the persistence level according to PySpark definitions. Defaults to StorageLevel.DISK_ONLY.

      :returns: Spark Dataframe with the data
      :rtype: :class:`pyspark.sql.DataFrame`
