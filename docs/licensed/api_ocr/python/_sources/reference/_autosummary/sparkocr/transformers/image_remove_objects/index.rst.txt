.. py:class:: ImageRemoveObjects(inputCol=None, outputCol=None, minSizeObject=None)

   Bases: :py:obj:`sparkocr.transformers.image_base_transformer.ImageBaseTransformer`

   Image transformer for remove background objects.
   It support removing:
    - small objects without avoiding symbols with font size defined by minSizeFont
    - objects less then minSizeObject
    - holes less then minSizeHole
    - objects more then maxSizeObject
