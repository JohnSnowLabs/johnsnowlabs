   Bases: :py:obj:`pyspark.ml.Transformer`, :py:obj:`pyspark.ml.param.shared.HasInputCol`, :py:obj:`pyspark.ml.param.shared.HasOutputCol`, :py:obj:`pyspark.ml.util.DefaultParamsReadable`, :py:obj:`pyspark.ml.util.DefaultParamsWritable`, :py:obj:`sparkocr.transformers.params.HasKeepInput`

   Filters rows according to regions labels.

   Detailed Description:
   This transformer receives rows containing a column with regions, the rows are filtered, either whitelisted,
   or blacklisted according to the labels present in this regions column.

   E.g., keep only documents containing 'text' and 'title' labels in regions,

   filterer = RegionsFilterer().       setWhiteList(["text", "title"])

   filterer.transform(input_df)


   E.g., discard documents containing 'figure' within label regions,

   filterer = RegionsFilterer().       setBlackList(["figure"])

   filterer.transform(input_df)
