.. py:class:: PretrainedPipeline(name, lang='en', remote_loc=None, parse_embeddings=False, disk_location=None)

   Loads a fully constructed and trained Spark OCR/NLP pipeline,
   ready to be used.

   This way, a whole pipeline can be defined in 1 line. Additionally, the
   :class:`.LightPipeline` version of the model can be retrieved with member
   :attr:`.light_model`.

   :param name: Name of the PretrainedPipeline. These can be gathered from the Pipelines
                Page.
   :type name: str
   :param lang: Langauge of the model, by default 'en'
   :type lang: str, optional
   :param remote_loc: Link to the remote location of the model (if it was already downloaded),
                      by default None
   :type remote_loc: str, optional
   :param parse_embeddings: Whether to parse embeddings, by default False
   :type parse_embeddings: bool, optional
   :param disk_location: Path to locally stored PretrainedPipeline, by default None
   :type disk_location: str , optional
