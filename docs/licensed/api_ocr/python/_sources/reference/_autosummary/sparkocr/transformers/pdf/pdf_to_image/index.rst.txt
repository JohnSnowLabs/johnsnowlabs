   Bases: :py:obj:`pyspark.ml.wrapper.JavaTransformer`, :py:obj:`pyspark.ml.param.shared.HasInputCol`, :py:obj:`pyspark.ml.param.shared.HasOutputCol`, :py:obj:`sparkocr.transformers.params.HasKeepInput`, :py:obj:`sparkocr.transformers.params.CompressOutputImage`, :py:obj:`pyspark.ml.util.JavaMLReadable`, :py:obj:`pyspark.ml.util.JavaMLWritable`

   Transform Pdf document to single image or to several images per each page.
   Input is a column with binary representation of PDF document.
   As output generate column with image and page number.
   Explode each image as separate row in specified color model.
