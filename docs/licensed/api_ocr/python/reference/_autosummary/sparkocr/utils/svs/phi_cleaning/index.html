remove_phi(input, output, tags=predefined_tags, append_tags=[], rename=False, verbose=False)#

Remove label images, macro images, and specified metadata from SVS files.

This function processes SVS files to remove sensitive metadata and associated images. By default, it removes specific metadata tags: “ImageDescription.Filename”, “ImageDescription.Date”, “ImageDescription.Time”, and “ImageDescription.User”.

Parameters: - input (str): The file path or directory containing the SVS files to be de-identified. - output (str): The file path or directory where the de-identified files will be saved. - tags (list, optional): A list of metadata tags to remove, replacing the default tags if provided. - append_tags (list, optional): Additional tags to remove, added to the defaults without overriding them. - rename (bool, optional): whether to rename the output svs file. Default is False. - verbose (bool, optional): whether to plot detailed logs or not. Default is False.

Returns: - None
