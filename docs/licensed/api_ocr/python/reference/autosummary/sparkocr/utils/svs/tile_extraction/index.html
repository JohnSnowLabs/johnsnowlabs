decodes_to_ycbcr(page, data)#

Whether tifffile returns this Aperio 33003 JPEG2000 segment in YCbCr. It does when the chroma isn’t subsampled; real Aperio files subsample it (J2K/YUV16), and then the decoder already converts to RGB. Read from the codestream’s SIZ.

Index of the slide thumbnail page, or None if the file has none.

Same rule as OpenSlide for Aperio: the second page, when it is untiled and not marked as label/macro by NewSubfileType. Pyramid levels are never returned.

get_target_level_tiles(flat_tiles_folder, output_folder=None, max_downsample=8.0)#

Select the coarsest pyramid level whose downsample factor from the highest-resolution level is within max_downsample. Falls back to the highest-resolution level if every level exceeds that.

Downsample factor between two levels is sqrt(tiles_A / tiles_B), since tile count scales with image area.

max_downsample has no universal default; tune it against ImageTextDetector’s score at a few candidate levels for your slides.

process_svs(svs_file, output_root, num_workers, level='auto', thumbnail=None, max_downsample=8.0)#

Record the tile grid of every pyramid level in output_root/<svs_filename>/grid_info.json and extract the tiles of one chosen level, plus the slide thumbnail if it has one, as JPEGs into …/selected/. …/all/ is kept for the redaction step’s layout.

Parameters: - svs_file (Path): path to the .svs file to process. - output_root (Path): parent directory under which <svs_filename>/{all,selected} is created. - num_workers (int): worker count for the tile-extraction process pool. - level (str or int, optional): ‘auto’ (default) picks the level via

get_target_level_tiles(max_downsample); pass an explicit pyramid level index to select it directly instead.

  • thumbnail: deprecated and ignored, the thumbnail is always extracted when present.

  • max_downsample (float, optional): only used when level=’auto’. Upper bound on how much coarser than the highest-resolution level the selected level may be; see get_target_level_tiles for how it’s applied and how to calibrate it. Default 8.0.

Returns: - None

svs_to_tiles(input_path, output_root, level='auto', thumbnail=None, max_downsample=8.0)#

Extract tiles from a single .svs file or every .svs file in a directory. Thin wrapper around process_svs() that resolves input_path to one or more files, batches directory input, and keeps going past per-file failures when processing a directory, raising at the end if any file failed.

Parameters: - input_path (str or Path): a .svs file, or a directory of .svs files. - output_root (str or Path): parent directory under which each <svs_filename>/{all,selected} is created. - level (str or int, optional): ‘auto’ (default) selects a level per file via

get_target_level_tiles(max_downsample); pass an explicit pyramid level index to select the same level for every file instead.

  • thumbnail: deprecated and ignored, each slide’s thumbnail is always extracted when present.

  • max_downsample (float, optional): only used when level=’auto’; see process_svs and get_target_level_tiles. Default 8.0.

Returns: - None
